A desktop-based Course Management System built with Python, Tkinter, and SQLite that automates academic operations through role-based authentication, enabling administrators, teachers, and students to manage courses, users, and digital learning materials efficiently.

The Course Management System (CMS) is a desktop-based application developed using Python 3, the Tkinter GUI toolkit, and SQLite as the backend database. The system is designed to digitalize and automate the day-to-day academic operations of an educational institute, with a focus on course management, student management, teacher management, and digital course material distribution. 
The application supports three main user roles: Administrator, Teacher, and Student. The Administrator manages login accounts for teachers and students through an admin dashboard that maintains records in a centralized users table, with a linkage to the teacher table for teacher profiles. The Teacher logs into a dedicated teacher dashboard and can create and update courses, manage student details, upload course materials (PDF syllabi/notes), and maintain their own profile, including a display picture. The Student accesses a student dashboard to view course details, browse and download course materials, and view a simple 
profile. 
Data persistence is handled by a single SQLite database file cms.db, which contains the main tables: users, teacher, student, course, and course_material. The system implements rolebased authentication, modular GUI windows, and file management for uploaded materials and profile images. Error messages, input validation, and confirmation dialogues enhance usability and reliability. Overall, the project successfully demonstrates how Python and SQLite can be used to build a comprehensive course management solution suitable for small institutes or as a college-level software engineering project.
